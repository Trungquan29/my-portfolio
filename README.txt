MY PORTFOLIO - NGUYỄN TRUNG QUÂN

Cấu trúc:
- index.html: Trang chủ
- about.html: Giới thiệu
- contact.html: Liên hệ
- css/style.css: Giao diện
- js/script.js: JavaScript
- images/logo.svg: Logo NQ
- images/avatar.svg: Ảnh minh họa tạm thời

CẦN CHỈNH TRƯỚC KHI NỘP:
1. Thay images/avatar.svg bằng ảnh cá nhân của bạn. Có thể đổi tên ảnh thành avatar.jpg rồi sửa src="images/avatar.svg" trong index.html và about.html thành src="images/avatar.jpg".
2. Sửa email mẫu trong contact.html thành email thật hoặc xóa nếu không muốn công khai.
3. Thêm link GitHub thật nếu có.

Chạy thử: mở index.html bằng trình duyệt.
Deploy GitHub Pages: tạo repository tên my-portfolio, upload toàn bộ nội dung bên trong thư mục này, vào Settings > Pages > Deploy from a branch > main > /(root) > Save.
